# 05 — Diagrams in the Editor: vendoring, drawing, placement

Status: ready-for-agent
Spec: ../spec.md
Blocked by: 01

## What

Mermaid arrives in the repository, and the Editor's read pane draws a Diagram
with it. This is where the placement that keeps the CSP narrow (ADR-0016) is
written and proved; 06 puts the same placement on the public page.

## Scope

- **Vendoring.** `shared/mermaid.min.js` — the current Mermaid 11 release,
  pinned, the classic (non-module) build so it loads from `file://` — with
  `shared/mermaid.LICENSE`. Its version is in a first-line comment.
- **`bin/build`** copies it to `editor/mermaid.min.js` and
  `site/public/mermaid.min.js`; its header comment lists the two new outputs.
  `bin/test`'s drift check covers both, and the probe's repathing resolves the
  Editor's copy from `tests/`.
- **Loading.** `editor/ui.js` adds one `<script src="mermaid.min.js">` the first
  time a render finds a Diagram, and never on a Document without one.
- **Configuration.** `startOnLoad: false`, `securityLevel: 'strict'`, the
  `base` theme with variables read from the page's CSS custom properties, the
  page's font family.
- **Placement**, written as one function the page can share in spirit with 06:
  `mermaid.render()` → string → `DOMParser` → each `<style>`'s text into one
  `<style>` carrying the nonce, when there is one → each `style` attribute
  into the element's CSSOM → the cleaned SVG replaces the `<pre>`. The copy
  button stays and copies the source.
- **Failure.** `render()` throwing leaves the code block and prints Mermaid's
  message under it, in the read pane.
- **Theme.** `T` redraws every Diagram in the read pane.
- **`bin/test`'s Editor network scan** keeps scanning `editor.js` and `ui.js`
  and does not scan the vendored file; its comment says why. The claim in
  `ui.js`'s header is updated to the one in CONTEXT.md's **Editor** entry.

## Stop condition

If Mermaid needs `'unsafe-eval'`, or any `style` attribute survives placement,
stop and bring it back to grilling. ADR-0016's rejected alternative is not
taken without a decision.

## Out

The public page, which is 06. Drawing in the write pane. Any change to
`renderDoc` — a Diagram's HTML is a code block's HTML.
